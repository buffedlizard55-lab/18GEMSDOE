Project aims

  • Develop geologically credible additions to the fault map, with special attention to extensions, splays, and parallel strands of known fault zones when supported by evidence.
  • Test physical signals rather than visual resemblance or generic feature stacking.
  • Maximize expected competition value without confusing proxy validation with public leaderboard or hidden-test performance.
  • Preserve a reproducible, reviewable path from authorized source data to a final output.

Core Values

Maximize P(Win)

Reserve limited submission opportunities for distinct candidates that pass preregistered spatial tests. Do not spend a slot on a duplicate, proxy-only story, or score-chasing tweak.

Own the Outcome

Reproduce before trusting. Keep failures, source hashes, limitations and attribution questions visible. Stop when data or evidence is not good enough.

Mechanism & falsification

For every candidate, explain why a fault produces the predicted signal, name a non-fault process that could mimic it, and preregister a test that can reject the idea.

What counts as evidence

  • Official competition result: manually verified platform record with date and account attribution, when known.
  • Independent check: a defined file/hash/test rerun in this project. Scope of verification must be explicit.
  • Group-reported result: sibling-project claim, useful as prior context but not accepted as an independent 18GEMSDOE result.
  • Inference or hypothesis: reasoned proposal only; never labeled as an observed result.
